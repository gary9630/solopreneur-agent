# GitHub Pages HTML Slides Design

**Goal:** Build a single-file, GitHub Pages-ready HTML slide deck that documents the Solopreneur Agent MVP, its live workflow, tool surface, and demo commands.

**Architecture:** The deck lives at `docs/index.html` so GitHub Pages can use the `docs/` folder as the site source. It is a self-contained static page with inline CSS and JavaScript, keyboard navigation, responsive 16:9 slides, canvas-based tech background, diagrams, and command/code panels. It uses no external slide template.

**Content Plan:**
- Cover and positioning for NVIDIA NemoClaw Hackathon.
- Solopreneur pain points and product promise.
- Architecture: Telegram, OpenClaw, host tool gateway, NIM, Odoo, Linear, GitHub.
- First-class OpenClaw tool catalog and live safety gates.
- Odoo workflow and Telegram business-card demo.
- Documentation slides with setup commands, live commands, and test commands.
- Demo run order, verification evidence, and judging story.

**Style:** Dark technical interface, cyan/lime accents, restrained terminal panels, system diagrams, live status chips, and no decorative blobs or landing-page hero treatment.
